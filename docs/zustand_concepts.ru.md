# Основные концепции Zustand

Zustand (нем. "состояние") — это минималистичная библиотека для управления состоянием в React. Она проще и легче, чем Redux, но при этом очень мощная.

## 1. Store (Хранилище)
Store — это объект, который хранит состояние вашего приложения и функции для его изменения. В отличие от Redux, в Zustand может быть **несколько** store, но обычно создают один основной.

```typescript
import { create } from 'zustand'

const useStore = create((set) => ({
  bears: 0,
  increasePopulation: () => set((state) => ({ bears: state.bears + 1 })),
  removeAllBears: () => set({ bears: 0 }),
}))
```

## 2. State (Состояние)
Это данные, которые хранятся в store. В примере выше `bears` — это часть состояния. Состояние в Zustand иммутабельно (неизменяемо напрямую), изменения происходят через функцию `set`.

## 3. Actions (Действия)
Это функции, которые изменяют состояние. В примере выше `increasePopulation` и `removeAllBears` — это actions. В Zustand actions находятся прямо в store, вместе с данными.
*   **Синхронные actions:** Просто меняют стейт.
*   **Асинхронные actions:** Могут делать запросы к API, ждать ответа, а потом вызывать `set`.

## 4. Subscribers (Подписчики / Хуки)
Компоненты "подписываются" на изменения в store, используя хук, который возвращает функция `create`.

```tsx
function BearCounter() {
  const bears = useStore((state) => state.bears)
  return <h1>{bears} around here ...</h1>
}
```
Когда `bears` изменится, компонент `BearCounter` автоматически перерисуется.

## 5. Middleware (Промежуточное ПО)
Zustand поддерживает middleware для расширения функционала. Самые популярные:
*   **persist:** Автоматически сохраняет состояние в `localStorage` или `sessionStorage`.
*   **devtools:** Позволяет использовать Redux DevTools для отладки.
*   **immer:** Позволяет писать мутабельный код (как в Vue или MobX) внутри `set`.

## Почему Zustand?
*   **Простота:** Меньше шаблонного кода (boilerplate) по сравнению с Redux.
*   **Хуки:** Естественная интеграция с React через хуки.
*   **Производительность:** Компоненты ререндерятся только тогда, когда меняются данные, которые они используют (благодаря селекторам).
*   **Гибкость:** Работает как с React, так и без него (vanilla js).
