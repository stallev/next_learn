# Обзор курса и итоговый функционал

В этом документе описано, какое приложение вы создадите в процессе обучения, и какие навыки вы приобретете.

## Итоговый функционал приложения

К концу курса у вас будет Next.js приложение со следующими возможностями:

1.  **Список постов:**
    *   Загрузка данных из внешнего API (`jsonplaceholder`).
    *   Отображение индикаторов загрузки (Loading) и ошибок (Error).
    *   Кеширование данных (предотвращение повторных запросов).

2.  **Интерактивность:**
    *   **Счетчик:** Простой пример глобального состояния для понимания основ.
    *   **Избранное:** Возможность добавлять посты в "Избранное" (лайкать).
    *   **Фильтрация/Сортировка:** (Опционально) Возможность фильтровать посты.

3.  **Персистентность (Сохранение данных):**
    *   Список "Избранного" будет сохраняться в `localStorage` браузера.
    *   Данные не пропадут после перезагрузки страницы.

4.  **Архитектура:**
    *   Разделение логики на модули (Slices).
    *   Правильная интеграция с Next.js App Router (SSR/RSC).

## Чему вы научитесь (Skills Acquired)

Пройдя этот курс, вы освоите библиотеку Zustand и научитесь применять её в реальных проектах.

### 1. Основы управления состоянием (State Management)
*   Как создавать глобальное хранилище (Store).
*   Как читать данные (State) и изменять их (Actions).
*   Отличие от `useState` и `Context API`.

### 2. Асинхронность и API
*   Как обрабатывать HTTP-запросы внутри Zustand.
*   Управление статусами загрузки (`loading`, `success`, `error`).
*   Как выносить бизнес-логику из компонентов в Store.

### 3. Оптимизация производительности
*   **Селекторы (Selectors):** Как подписываться только на нужные части состояния, чтобы избежать лишних ререндеров.
*   **Shallow Comparison:** Как эффективно сравнивать объекты.

### 4. Продвинутые паттерны
*   **Middleware:** Использование встроенных middleware (persist, devtools).
*   **Slices Pattern:** Как разбивать большой Store на маленькие независимые части (слайсы) для удобства поддержки.

### 5. Интеграция с Next.js
*   **Server Side Rendering (SSR):** Понимание проблем гидратации (Hydration Mismatch).
*   **Изоляция состояния:** Как создавать Store для каждого запроса, чтобы данные пользователей не смешивались на сервере.
*   **Store Provider:** Использование Context API для передачи Store в дерево компонентов.

Этот набор навыков позволит вам строить масштабируемые и производительные React-приложения любой сложности.
